# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository: https://github.com/nabilzahran06/library-system.git
2. Masuk ke folder project dengan perintah `cd library-system`.
3. Jalankan `composer install`.
4. Buat file `.env` dari `.env.example`.
5. Jalankan `php artisan key:generate`.
6. Buat database MySQL dengan nama `belajar_laravel`.
7. Jalankan `php artisan migrate`.
8. Jalankan `php artisan serve`.
9. Buka `http://127.0.0.1:8000` di browser.
